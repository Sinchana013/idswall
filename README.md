# Simple IDS + Firewall (Simple IDPS)

Welcome to the **Simple IDS + Firewall** project!

The complete project implementation, test suites, documentation, and demo are located in the [`simple_idps/`](./simple_idps) directory.

### Quick Start:
```powershell
# 1. Run the offline simulation demo:
python demo.py
# (or cd simple_idps && python demo.py)

# 2. Run the test suite:
python -m unittest discover -s simple_idps/tests

# 3. Read the complete documentation:
# Open simple_idps/README.md
```

For full documentation on setup, Scapy, Npcap, Windows Defender Firewall management, safety policies, and limitations, please see:
➡️ **[simple_idps/README.md](./simple_idps/README.md)**
